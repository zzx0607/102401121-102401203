# 测试说明与简易教程

采用 pytest + Flask test_client，无需启动真实 HTTP 服务器。学习要点：准备输入（Arrange），调用被测函数或接口（Act），断言输出与数据库状态（Assert）。`conftest.py` 的 fixture 为每个测试创建临时数据库，避免相互污染。

运行 `python -m pytest -q`；运行单个模块 `python -m pytest tests/test_posts.py -v`。

例如 `test_owner_permissions`：用一个客户端发布，再用另一个没有相同 Cookie 的客户端请求结束和删除，断言403，最后确认原记录未结束。它验证后端权限，不只是验证按钮隐藏。

覆盖场景：寻物/招领发布及各自结束状态、重复结束、三项必填空白、长度上界、非法类别、未带CSRF、跨访客修改与删除、HTML转义、删除后404、关键词和组合筛选、无匹配、百分号按字面搜索、英文大小写、多空格、结束状态筛选、相似线索排除已结束/同类型/其他类别、重启后数据保留、事务失败回滚、真实图片上传与删除、假图片、图片超过5MB、请求超过6MB。

测试数据依据正常值、空值、边界值、非法值和不同身份组合构造，不仅覆盖成功流程。


1. 发布一条寻物、一条同类别招领，核对首页、详情和相似线索。
2. 连续选择不同图片，再取消，确认预览和实际上传一致。
3. 搜索后筛选类别、地点和状态，查看空结果提示。
4. 复制联系方式；在我的发布结束记录；刷新首页确认状态。
5. 无痕窗口能浏览普通窗口发布的数据，但不能管理这些记录。
6. 重启 Flask 后，原浏览器仍能管理已发布记录。
