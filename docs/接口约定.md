# 接口约定

页面：`GET /` 首页，`GET /publish` 发布，`GET /posts/<id>` 详情，`GET /my-posts` 我的发布。

| 方法 | 地址 | 输入 | 返回 |
|---|---|---|---|
| GET | /api/posts | q、type、cat、place、status（active/done），均可选 | posts 列表 |
| POST | /api/posts | multipart/form-data，见下表 | 201：post、redirect |
| GET | /api/posts/<id> | 路径 ID | post（含 contact） |
| PATCH | /api/posts/<id>/finish | 无请求体 | post（更新后） |
| DELETE | /api/posts/<id> | 无请求体 | {"ok":true} |
| GET | /uploads/<name> | 系统生成的图片名 | 图片文件 |

| 发布字段 | 说明 |
|---|---|
| type | 寻物或招领，必填 |
| name | 物品名，去空白后1–40字 |
| cat | 证件/钥匙/水杯/雨伞/耳机/书籍/其他，默认其他 |
| place | 地点，去空白后1–60字 |
| time | 遗失/拾取时间文字，0–40字 |
| description | 描述，0–500字 |
| contact | 联系方式，去空白后1–80字 |
| image | 可选图片，最多5MB |

POST/PATCH/DELETE 必须携带当前页面 meta[name=csrf-token] 的值作为 `X-CSRF-Token` 请求头，并携带当前 Session Cookie。发布者 ID 由后端决定，客户端不能指定。

返回字段包括 id、type、name、cat、place、time、description、image、done、created_at、mine、status_label。owner_id 不对外输出；列表不含联系方式。详情的折叠是交互设计，并非联系方式访问权限。

400：校验不通过；403：CSRF 或发布者权限失败；404：记录不存在；413：请求体过大。错误为 `{"error":"具体说明"}`。重复结束已结束记录返回200，不会重复产生记录。时间字段 created_at 为 SQLite UTC 写入时间，页面主要展示用户填写的事件时间。

搜索按空格拆词，所有词均须出现在名称、类别、地点或描述中，不区分英文字母大小写。所有筛选条件同时满足。
